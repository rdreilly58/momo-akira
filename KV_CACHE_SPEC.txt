2.  **Forward Pass (mutates cache):**
    ```python
    logits = model(input_ids, cache=cache)
    # IMPORTANT: The model call returns ONLY logits.
    # The `cache` object is mutated in-place and its offset is advanced.
    ```

3.  **Position Tracking:**
    ```python

    ```

4.  **Rollback (CRITICAL):**
    ```python

        for layer in cache:
            layer.trim(n)
    # `trim(n)` removes the last `n` tokens from the cache's history.
    # This is how you implement rollback on rejection. It works.
    ```

5.  **"Peeking" at Next Logits (CRITICAL):**
    To get the logits for the *next* token without permanently advancing the cache, you must use a "peek" pattern:
    ```python
    def peek_logits(model, token_id, cache):
        """Gets logits for the position after token_id without advancing the cache."""
        logits = model(mx.array([[token_id]]), cache=cache) # Cache advances by 1
        trim_cache(cache, 1) # Immediately undo the advance
        return logits[0, -1, :]
    ```
